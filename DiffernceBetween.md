difference between precision and recall
Precision: Answers the question: "Out of all things predicted as positive, how many were actually positive?" It helps reduce false positives (false alarms).
Precision = True Positives / (True Positives + False Positives)


Recall: Answers the question: "Out of all actual positive cases in the data, how many did the model find?" It helps reduce false negatives (missed cases). Also known as sensitivity or true positive rate.
Recall = True Positives / (True Positives + False Negatives)
